    :help // POCKET-JOKER(1)

    Everything is a command.

    01

    Move

    h and l move the cursor. Counts work: 3l. Jump with 0, $, gg, or G.

    02

    Compose

    Space toggles one card. v starts a visual range; move, then use Space to keep it.

    03

    Select groups

    sh adds every heart. S5 replaces the selection with every five. sf adds all face cards.

    04

    Act

    p plays selected cards. dd discards them. An operator plus target acts directly: dh discards every heart.

    05

    Recover

    u restores the previous selection. c clears it. . repeats the last action. r starts a new round.

    06

    Command

    : enters EX mode. Commands include select, add, discard, play, clear, sort, restart, help, and normal.

    Press ? or Esc to close the manual.
